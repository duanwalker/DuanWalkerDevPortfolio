## Problem

Logic App definitions are stored as JSON, but documenting what one actually does — its triggers, its actions, how the pieces connect — is normally a manual write-up. FlowScribe.AI parses a Logic App JSON definition and generates Microsoft-style documentation of its structure, triggers, and actions.

## Architecture

A Razor Pages application, written in C#, that reads a Logic App JSON definition and generates the documentation directly from it.

Documentation generation itself is AI-driven: FlowScribe sends the parsed Logic App structure to Anthropic's Claude via the Messages API, which writes the prose description and produces the Microsoft-style write-up shown below. Parsing and orchestration stay in C#; Claude is the layer that turns structure into readable documentation.

## What I'd do differently

Separate business identity from day one. FlowScribe started on my personal email and API accounts, and untangling billing, keys, and account boundaries later cost real debugging time — including an auth failure that traced back to credentials split across two accounts. Infrastructure hygiene is a launch-day decision, not a scale-day one.
